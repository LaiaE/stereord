# stereord
Please install stereord from GitHub using `devtools::isntall_github("LaiaE/stereord")`

# Update
This R package contains the function `OSM()` that allows you to fit the Ordered Stereotype Model (OSM) (`repar = TRUE`)  and the Stereotype Model (SM) (`repar = FALSE`). 

Please, if you find any issues using the function email egeaclaia@myvuw.ac.nz, note that this is the first version I share.  Also, if you have any improvements or aspects that you think will be useful for you or other people, please email me, I am happy to implement them in the function.
